# Web UI Guidance Skill

用途：帮助 X-Amplicon Web UI Agent 准确引导用户操作浏览器界面，避免编造不存在的页面、按钮、结果或运行状态。回复时优先给出“页面 -> 区域 -> 按钮 -> 成功后看到什么”。

## 全局布局

- 左侧是固定导航栏，从上到下依次是：`Agent 助手`、`新建分析`、`运行监控`、`结果`、`数据库`、`工作台`、`设置`。
- 顶部栏左侧显示后端状态，正常时为“已连接”；右上角是语言下拉框，可切换中文或英文。
- 不知道用户当前在哪个页面时，先让用户从左侧导航进入对应页面，不要假设用户已经打开了某个面板。
- 不要声称已经替用户点击按钮、保存设置、启动任务或删除历史。只能指导用户操作或解释结果。
- 不要建议删除 `work/`、`work/06_final` 或真实分析输出文件。

## Agent 助手

- 页面顶部是说明横幅，主按钮是`开始向导式分析`，旁边有`运行监控`和`结果`按钮。
- 右侧模型状态卡显示 Agent 状态、模型、provider，并提供`刷新`和`设置`按钮。
- 下方左侧大面板是`分析对话`，顶部有快捷问题按钮：`开始分析`、`检查 metadata`、`设置差异比较`、`没有图表`。右上角有 LLM/规则状态和`新对话`按钮。
- 对话框底部是输入框和`发送`按钮。用户可以直接问怎么开始、怎么检查输入、怎么解释日志或怎么查看结果。
- 右侧上方面板是`项目上下文`，可选择 Web UI 项目，并用复选框决定是否附带当前项目上下文。
- 右侧下方面板是`引导式工作流`，顺序是：创建项目、检查输入、设置分组、运行 preflight、查看输出。底部有`新建分析`、`运行监控`、`结果`按钮。

## 新建分析

- 页面顶部是 5 步 wizard：`项目`、`输入文件`、`样本分组`、`分析参数`、`检查并运行`。底部有`上一步`和`下一步`。
- 第 1 步`项目`：填写项目名称、分析类型、项目目录、输出目录。输出目录右侧有`选择文件夹`。点击`创建项目`后才能继续。
- 第 2 步`输入文件`：填写 metadata 路径、FASTQ 文件夹、SampleID 列、分组列、R1/R2 后缀。metadata 右侧有`选择文件`，FASTQ 文件夹右侧有`选择文件夹`。按钮包括`检查 metadata`、`预览 FASTQ 配对`、`metadata 和 FASTQ 配对都检查`。成功后会出现 metadata 摘要和配对摘要。
- 第 3 步`样本分组`：选择分组列和参考组，表格显示每组样本数。差异比较用 CASE:CONTROL 方向，选择 case group 和 control group 后点击`添加比较`，也可以用参考组自动生成比较。
- 第 4 步`分析参数`：设置 feature method、taxonomy database、chimera mode、filter route、rarefaction depth、threads。高级参数默认展开，包含 reference db、otutab method、fastq_stripleft/right、fastq_maxee_rate、identity、sintax_cutoff、rarefaction seed、beta tree path、command timeout、color palette。
- 第 5 步`检查并运行`：先点击`写出参数`或直接点击`运行 preflight`。preflight 成功后，`启动完整分析`才是安全路径。完整分析会按顺序运行 pipeline、visualization、differential（如已设置）、report。

## 运行监控

- 页面右上角有`刷新`和`打开结果`。只有选中的任务完成后，`打开结果`才有意义。
- 左侧面板是`最近任务`，顶部显示任务数量；可以在“按任务 ID 打开”输入框粘贴 job id，再点`打开`。
- 任务列表中每张任务卡显示 job type、job id、完成或开始时间、状态。点击任务卡会选中它。
- 右侧面板是`任务详情`，显示任务 ID、任务类型、项目、PID、工作目录、返回码。
- 中部`进度`面板显示 Preflight、输入复制、双端合并、质量过滤、去冗余、Feature 生成、物种注释、抽平、多样性分析、可视化、报告等阶段状态。
- 底部`日志`面板包含用户可读状态和技术日志。按钮包括`刷新日志`、`取消任务`、`复制命令`、`下载日志`、`隐藏日志`。运行中任务可取消，完成或失败任务主要查看日志。

## 结果

- 页面右上角有项目选择下拉框和`刷新`按钮。下拉框可选当前工作目录或已有 Web UI 项目。
- Tabs 依次是：`摘要`、`QC`、`Alpha 多样性`、`Beta 多样性`、`物种组成`、`差异比较`、`报告`、`Provenance`、`文件`。
- `摘要`显示样本数、数据库、feature method、输出目录、开始时间、图表数量，并嵌入 plots index。
- `QC`显示运行步骤表和关键输出文件。
- `Alpha 多样性`可选择指标，显示 boxplot、barplot、rarefaction 和 alpha 表。
- `Beta 多样性`可选择距离，显示 PCoA、CPCoA、heatmap、组间检验和距离矩阵下载。
- `物种组成`可选择 taxonomy level，显示 stacked bar、heatmap 和物种丰度表。
- `差异比较`可选择 comparison，显示方向、测试 feature 数、显著 feature 数、volcano、heatmap 和结果表。
- `报告`可点击`生成报告`，并查看 HTML 报告、下载 Markdown 和 report_data。
- `Provenance`可复制复现命令，下载 `provenance.json` 和 `run_summary.json`。
- `文件`可浏览 final 目录、搜索文件、打开文件夹、预览文本、打开 HTML 或下载文件。
- 如果提示没有 final output directory 或没有结果，应先回到`新建分析`运行完整分析，或到`运行监控`确认任务是否完成。

## 数据库

- 页面右上角有`刷新`和`检查`按钮。
- 顶部面板包含 Registry 路径输入框和`计算 SHA-256`复选框。大型 FASTA 计算 hash 较慢，默认不建议开启。
- `已注册数据库`表格显示名称、版本、来源、taxonomy 格式、FASTA 路径、状态、大小和操作。每行右侧`检查`用于验证该数据库。
- `选中数据库`面板显示当前数据库的名称、版本、来源、taxonomy 格式、数据库类型、大小、修改时间、用途、FASTA 路径和别名。
- `注册本地数据库`表单用于登记自定义 FASTA，只保存路径和 metadata，不复制大型 FASTA 文件。需要填写名称、版本、taxonomy 格式、FASTA 路径、数据库类型、别名、用途和可选 SHA-256，然后点击`注册数据库`。

## 工作台

- 工作台是概览页，顶部推荐先问 Agent，再运行 16S 分析。主要按钮是`询问 Agent`、`向导式分析`、`查看结果`。
- `环境状态`显示后端状态、Python、项目根目录和 API 地址，并有`刷新`按钮。
- `快捷操作`提供进入 Agent 助手、设置、数据库、运行监控的按钮。
- `最近项目`显示项目表，右上角有`清除全部历史`。每个项目行有`删除历史`。这些只清理 Web UI 历史和任务记录，不删除真实分析输出。
- `结果快捷入口`提供 Alpha 多样性、Beta 多样性、物种组成、差异比较、报告按钮。

## 设置

- 页面右上角主按钮是`保存设置`。普通设置改完后需要点击它才会保存。
- `Agent LLM 访问`面板用于配置模型、API base URL 和 API key。点击`保存 LLM 设置`后写入本地 `.env`。API key 不会明文回显。
- `运行环境`面板包含界面语言、Python 可执行文件、USEARCH 路径、VSEARCH 路径。
- `默认分析路径`面板包含默认输出目录、默认 metadata 路径、默认 FASTQ 文件夹、默认 SampleID 列、默认分组列。输出目录和 FASTQ 有`选择文件夹`，metadata 有`选择文件`。
- `可视化默认值`面板包含默认图表格式和授权访问目录。授权目录下方有`添加文件夹`，会把选择的目录追加到 textarea，但仍需点击`保存设置`。

## 回复准则

- 引导新用户时，优先推荐：`Agent 助手`确认目标 -> `新建分析`创建项目 -> 检查 metadata 和 FASTQ 配对 -> 设置分组与差异比较 -> 运行 preflight -> 启动完整分析 -> `运行监控`看状态 -> `结果`看图表、报告和 provenance。
- 用户问“按钮在哪”时，回答左侧导航、页面区域和按钮名称。
- 用户问“为什么没结果/没图表”时，先让用户到`运行监控`确认最近任务是否完成，再到`结果`选择项目并刷新；不要直接说结果已经生成。
- 用户问“怎么开始完整 16S 分析”时，必须包含：进入`新建分析`、点击`创建项目`、检查 `metadata`、检查 FASTQ 配对、运行 `preflight`、启动完整分析、最后到`结果`查看输出。
